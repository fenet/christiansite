# CF Professionals — Project Foundation

Project skeleton for the CF Professionals website (frontend + backend).

Structure
- frontend/: Vite + React app
- backend/: Node.js + Express API

Frontend setup
1. cd frontend
2. npm install
3. npm run dev

Backend setup
1. cd backend
2. npm install
3. npm start

Default local URLs
- Frontend: http://localhost:5173
- Backend: http://localhost:5001

Environment
- frontend/.env.example -> `VITE_API_BASE_URL=`
- backend/.env.example -> `PORT=` and `NODE_ENV=`
